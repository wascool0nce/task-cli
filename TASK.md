# task-cli

Task tracker — это проект для отслеживания и управления вашими задачами. В этом задании вам нужно создать простой интерфейс командной строки (CLI), который позволит отслеживать, что вам нужно сделать, что вы уже сделали и над чем вы работаете сейчас. Этот проект поможет вам попрактиковать навыки программирования, включая работу с файловой системой, обработку пользовательского ввода и создание простого CLI-приложения.

# Требования

Приложение должно запускаться из командной строки, принимать действия пользователя и входные данные в виде аргументов, а также хранить задачи в JSON-файле. Пользователь должен иметь возможность:

- Добавлять, обновлять и удалять задачи
- Отмечать задачу как выполняемую или завершённую
- Выводить список всех задач
- Выводить список всех завершённых задач
- Выводить список всех незавершённых задач
- Выводить список всех задач в процессе выполнения

Вот несколько ограничений, которые помогут направить реализацию:

- Для создания проекта можно использовать любой язык программирования.
- Используйте позиционные аргументы командной строки для принятия пользовательского ввода.
- Используйте JSON-файл для хранения задач в текущей директории.
- JSON-файл должен создаваться автоматически, если он не существует.
- Используйте встроенный модуль файловой системы выбранного языка программирования для работы с JSON-файлом.
- Не используйте внешние библиотеки или фреймворки для создания этого проекта.
- Обеспечьте корректную обработку ошибок и пограничных случаев.

# Пример

Ниже приведён список команд и примеры их использования:

```bash
# Добавление новой задачи
task-cli add "Buy groceries"
# Вывод: Task added successfully (ID: 1)

# Обновление и удаление задач
task-cli update 1 "Buy groceries and cook dinner"
task-cli delete 1

# Отметка задачи как выполняемой или завершённой
task-cli mark-in-progress 1
task-cli mark-done 1

# Вывод списка всех задач
task-cli list

# Вывод задач по статусу
task-cli list done
task-cli list todo
task-cli list in-progress
```

# Свойства задачи

У каждой задачи должны быть следующие свойства:

- `id`: уникальный идентификатор задачи
- `description`: краткое описание задачи
- `status`: статус задачи (todo, in-progress, done)
- `createdAt`: дата и время создания задачи
- `updatedAt`: дата и время последнего обновления задачи

Убедитесь, что эти свойства добавляются в JSON-файл при создании новой задачи и обновляются при изменении задачи.
